# trade

한국투자증권 KIS Open API를 이용한 국내 ETF 단타 자동매매 Python 프로그램

## 개요

- 변동성이 큰 국내 ETF를 대상으로 단타 자동매매
- Python 기반 (Python 3.12+)
- 한국투자증권 Open API(KIS) 활용
- 모의투자(paper) / 실전투자(real) 환경 전환 지원

## 매매 전략

| 지표 | 매수 조건 | 매도 조건 |
|---|---|---|
| RSI (14일) | < 35 (과매도) | > 65 (과매수) |
| 이동평균 | 단기(5일) ≥ 장기(20일) | 단기(5일) < 장기(20일) |
| 거래량 | 최근 거래량이 5일 평균의 1.5배 이상 | — |
| 익절 | — | 수익률 +1.5% 도달 |
| 손절 | — | 수익률 -0.7% 도달 |

매수는 위 세 조건을 **모두** 충족할 때 실행됩니다.  
매도는 RSI 과매수 **또는** 데드크로스, 익절/손절 중 **하나라도** 충족하면 실행됩니다.

## 파일 구성

```
trade/
├── config.py       # 환경변수 로딩 및 전략 파라미터
├── kis_api.py      # KIS REST API 클라이언트 (인증, 시세, 주문, 잔고)
├── strategy.py     # RSI / 이동평균 / 거래량 전략 신호 산출
├── position.py     # 포지션 관리 (진입/청산/익절/손절 판단)
├── trader.py       # 메인 봇 (장 시간 감지 → 루프 → 매매 실행)
├── requirements.txt
└── .env.example    # 환경변수 예시
```

## 설치 방법

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 환경변수 파일 생성
cp .env.example .env

# 3. .env 파일에 API 키 및 계좌 정보 입력 (아래 설정 항목 참고)
```

## 환경변수 설정 (`.env`)

| 변수명 | 설명 | 예시 |
|---|---|---|
| `KIS_APP_KEY` | KIS API 앱 키 | `PSxxxxxx...` |
| `KIS_APP_SECRET` | KIS API 앱 시크릿 | `xxxxxxxx...` |
| `KIS_ACCOUNT_NUMBER` | 계좌번호 앞 8자리 | `12345678` |
| `KIS_ACCOUNT_PRODUCT_CODE` | 계좌 상품 코드 | `01` |
| `KIS_ENV` | 환경 (`real` 또는 `paper`) | `paper` |
| `MAX_BUY_AMOUNT` | 1회 최대 매수금액 (원) | `500000` |
| `MAX_POSITIONS` | 최대 동시 보유 종목 수 | `3` |
| `TAKE_PROFIT_RATE` | 익절 수익률 (%) | `1.5` |
| `STOP_LOSS_RATE` | 손절 비율 (%) | `0.7` |
| `ETF_SYMBOLS` | 매매 대상 ETF 종목코드 (쉼표 구분) | `069500,114800,122630` |

> API 키는 [한국투자증권 Open API 포털](https://apiportal.koreainvestment.com)에서 발급받을 수 있습니다.

## 실행 방법

```bash
python trader.py
```

실행 로그는 콘솔과 `trader.log` 파일에 동시에 기록됩니다.

## 동작 흐름

```
시작
 │
 ├─ 장 외 시간? → 60초 대기 후 재확인
 │
 └─ 장 중 (09:00 ~ 15:20)
      └─ 매 30초마다:
           ├─ 각 ETF 현재가 조회
           ├─ 보유 포지션 → 익절/손절 조건 확인 → 매도
           ├─ 일봉 데이터 조회 → RSI/MA/거래량 전략 평가
           └─ BUY 신호 + 미보유 + 신규매수허용 → 매수
```

## 주의사항

- **모의투자로 충분히 테스트한 뒤 실전투자를 진행하세요.**
- 본 프로그램은 참고용 예시이며, 투자 손실에 대한 책임은 사용자에게 있습니다.
- 레버리지·인버스 ETF는 변동성이 매우 크므로 주의가 필요합니다.
- KIS API 초당 호출 제한(약 20회/초)을 초과하지 않도록 종목 수와 조회 주기를 조정하세요.
