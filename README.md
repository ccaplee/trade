# trade

한국투자증권 KIS Open API를 이용한 국내 ETF 단타 자동매매 프로그램

## 개요
- 장 시작 후 거래량·변동성이 큰 ETF 상위 5개를 자동 선별
- 매수/매도 조건에 따라 자동 주문 실행
- Python 기반 / 한국투자증권 Open API(KIS) 활용
- 실전투자 및 모의투자 모두 지원

---

## 파일 구조

```
trade/
├── main.py            # 진입점 & 스케줄러

├── kis_auth.py        # KIS API 인증 (Access Token 관리)

├── trader.py          # 핵심 매매 로직 (포지션 관리 / 신호 판단)
├── requirements.txt   # 의존 패키지
├── .env.example       # 환경 변수 템플릿
└── .gitignore
```

## 설치 및 실행

### 1. 의존 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. 환경 변수 설정

```bash
cp .env.example .env
# .env 파일을 열어 KIS API 키, 계좌번호 등 실제 값으로 수정
```

[KIS Developers](https://apiportal.koreainvestment.com) 에서 앱 등록 후 `APP_KEY`와 `APP_SECRET`을 발급받아 입력하세요.

| 환경 변수 | 설명 | 기본값 |
|---|---|---|
| `KIS_APP_KEY` | 앱 키 | (필수) |
| `KIS_APP_SECRET` | 앱 시크릿 | (필수) |
| `KIS_ACCOUNT_NO` | 계좌번호 앞 8자리 | (필수) |
| `KIS_ACCOUNT_PRODUCT_CODE` | 계좌상품코드 | `01` |
| `KIS_MODE` | `paper` (모의) / `real` (실전) | `paper` |
| `MAX_POSITION_AMOUNT` | 종목당 최대 매수 금액(원) | `500000` |
| `MAX_POSITIONS` | 최대 동시 보유 종목 수 | `5` |
| `TARGET_PROFIT_RATE` | 목표 수익률 | `0.015` (1.5%) |
| `STOP_LOSS_RATE` | 손절 비율 | `0.007` (0.7%) |

### 3. 실행

```bash
python main.py
```

장 운영 시간(09:00~15:30) 이전에 실행해두면 자동으로 대기하다가 장 시작 후 매매를 시작합니다.

## 매매 전략

### ETF 선정 (매일 09:05, 이후 30분마다 재선정)
1. KIS API로 거래량 상위 ETF 목록 수집
2. 등락률 상위 ETF 목록 수집
3. 두 목록 병합 후 **복합 점수** (거래량 순위 × 0.5 + 등락률 × 0.5) 기준 상위 5개 선정
4. 가격 범위 필터 적용 (기본 5,000~200,000원)

### 매수 조건 (모든 조건 충족 시)
1. 현재가가 당일 시가 대비 **+0.3% 이상** 상승 (상승 추세 확인)
2. 전일 대비 등락률 **+0.5% 이상** (모멘텀 확인)
3. 20일 이동평균 이격도 **100 이상** (이평선 위)
4. 동시 보유 종목 수 < `MAX_POSITIONS`

### 매도 조건 (우선순위 순)
| 조건 | 설명 |
|---|---|
| 목표 수익률 달성 | 진입가 대비 +1.5% 이상 (설정 가능) |
| 손절 | 진입가 대비 -0.7% 이하 (설정 가능) |
| 강제 청산 | 15:20 이후 보유 포지션 전량 시장가 청산 |
